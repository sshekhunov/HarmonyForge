# HarmonyForge Score Editor

React app for viewing and editing MusicXML scores using OpenSheetMusicDisplay (OSMD).

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Features

- **ScoreEditor** component with:
  - OSMD viewer for MusicXML
  - **Open File** – load a `.xml` / `.musicxml` file
  - **Save File** – download the current score as MusicXML
